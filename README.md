# OASIS official website

Source for **https://oasisnextbd.github.io/OASIS_official_website/**: the OASIS company site and the
**Rod Bondhu** solar dryer site.

> **VenGuard moved.** Since November 2026 the VenGuard website, team dashboard, Firebase backend and
> VenGuard documents live in the private repository **oasisnextbd/venguard-website** and are published at
> **https://www.venguard.tech**. The VenGuard app is in **oasisnextbd/venguard-app**. This repository only
> keeps forwarding pages at the old addresses (`/VENGuard/…`, `/team/`) so printed links, ads and dealer
> QR stickers keep working. The history of the moved files is still here in git.

GitHub builds and publishes the site automatically from `main` (see [Publishing](#publishing)).
Nothing in this repository is generated by hand; the published files live only in the build output.

## Repository map

```
oasis-site/            OASIS company site (static)              → published at /
rodbondhu/             Rod Bondhu solar dryer website + live app → /Rod_Bondhu/ (bn), /Rod_Bondhu/en/, /Rod_Bondhu/app/
archive/               retired files kept for reference (not published)
scripts/               build.py (assembles _site/, writes the VenGuard forwarding pages), check_links.py
.github/workflows/     pages.yml: build, check and publish
```

## Work on it locally

```bash
pip install -r requirements.txt
python3 scripts/build.py                 # assembles everything into _site/
python3 scripts/check_links.py           # fails on any broken internal link
python3 -m http.server 8000 -d _site     # open http://localhost:8000/
```

Requirements: Python 3.10+.

## Publishing

Every push to `main` runs `.github/workflows/pages.yml`: build → link check → publish.
Pull requests run the same checks without publishing.
One-time setting: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Rules every change must follow

- **Public URLs are stable.** Pages are linked from ads, QR stickers and search results. Don't rename or move a
  published path without adding a redirect page at the old address. Never remove the VenGuard forwarding
  pages (`VENGUARD_PAGES` in `scripts/build.py`) or the forwarding script at the top of `oasis-site/404.html`.
- **Don't edit build output.** Change the source (`oasis-site/`, `rodbondhu/`) and rebuild.
- **No placeholder prices or contact details.** Use real values or leave the item out.
- **Keep it bilingual:** every Rod Bondhu string is written in both Bangla and English.
- **Small, described commits;** one topic per pull request.
